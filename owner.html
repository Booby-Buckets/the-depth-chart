⚡ Republish projected ratings

Recomputes the shared 2026-27 team power ratings (with your freshman projections applied) and publishes them to predictive_ratings — the single source of truth every visitor reads. Run this after a grade, coach, or roster change that moves team strength. The site otherwise only republishes when you save a freshman projection.

🏆 Republish awards

Recomputes the projected 2026-27 All-America + every conference all-conference / all-defense / all-freshman ballot from the current grades and publishes them to award_projections — the shared blob every visitor reads. Run this after a grade change so the ballots match the OVRs.

🔁 Rebuild projections

Re-runs the projection model against your live rosters so depth-chart edits — a newcomer's projected stat line, a roster move — flow into the projected ORtg / DRtg / net on the homepage. Kicks off a GitHub Actions job that rebuilds team_dna.json / team_eff.json and deploys (~1–2 min). Run this after editing projected stats.

📊 Refresh team projection box totals

Recomputes every team's projected per-game team line (PPG/RPG/APG/…) from the live rosters — reconciled to the player-page projection and normalized to a real 200-minute team — and writes them to team_projections, the table the index & analytics pages read. Fixes the inflated totals (e.g. impossible 40+ RPG) baked from the old un-normalized sum. Run after roster/projection changes.

📡 Data feeds

Per-player content, refreshed daily by the news/buzz GitHub Action. Fan buzz needs a free Reddit app key — if it shows not configured, add REDDIT_CLIENT_ID / REDDIT_CLIENT_SECRET as GitHub repo secrets and the next daily run populates it.
