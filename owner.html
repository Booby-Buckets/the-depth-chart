⚡ Republish projected ratings

Recomputes the shared 2026-27 team power ratings (with your freshman projections applied) and publishes them to predictive_ratings — the single source of truth every visitor reads. Run this after a grade, coach, or roster change that moves team strength. It also refreshes the projected awards from the same grades. The site otherwise only republishes when you save a freshman projection.

🏆 Republish awards

Recomputes the projected 2026-27 All-America + every conference all-conference / all-defense / all-freshman ballot from the current grades and publishes them to award_projections — the shared blob every visitor reads. Run this after a grade change so the ballots match the OVRs.

🔁 Rebuild projections

Re-runs the projection model against your live rosters so depth-chart edits — a newcomer's projected stat line, a roster move — flow into the projected ORtg / DRtg / net on the homepage. Kicks off a GitHub Actions job that rebuilds team_dna.json / team_eff.json and deploys, then publishes the team projections and rankings automatically once the new build is live (~2–3 min — keep the page open). After a roster sync or depth-chart change, this is the only button you need.

📊 Publish team projections

Publishes the per-game team lines (PPG/RPG/APG/…) from the last Rebuild projections job to team_projections — what the index, analytics and team pages read — then republishes the rankings. Replaces the SQL paste. Rebuild projections now runs this for you when its build lands — use it by hand only if that page was closed mid-rebuild.

📡 Data feeds

Per-player content, refreshed daily by the news/buzz GitHub Action. Fan buzz needs a free Reddit app key — if it shows not configured, add REDDIT_CLIENT_ID / REDDIT_CLIENT_SECRET as GitHub repo secrets and the next daily run populates it.
